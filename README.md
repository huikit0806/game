# Bakery sim (mobile)

Portrait bakery management game — tabs: **入貨 / 做包 / 店面 / 結算**, with hands-on bake steps.

## Agent skills

Curated Godot + UI / feel / crafting skills are installed for Cursor under `.agents/skills/` (see `AGENTS.md` and `skills-lock.json`).

```bash
npx skills list -a cursor
```
